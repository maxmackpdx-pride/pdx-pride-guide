## What is and is not saved

These are recipes and source pointers, not a new batch, a production rollout, a full asset archive or approval to publish photographs. No generated images, private reference files, credentials or personal records are included. No map/shader/header implementation is changed. Recent decorative header wallpapers are a different deliverable from these venue/destination/community photo treatments.

The PlaceZ source recipes reference bundled visual examples and CSS snapshots. Their text is preserved here, but those binaries/reference bundles are not copied in this save. Recover the exact originals and inspect them before claiming a visual match. Names of unavailable source-recipe files are retained as provenance, not represented as working local links. The detailed prompt is reconstructed from approved iterations, not a deterministic seed.

OutZide and SceneZ notes are explicitly labeled reconstructions where the original complete skill/preset was not available. Do not silently fill those gaps or describe them as recovered verbatim originals.
