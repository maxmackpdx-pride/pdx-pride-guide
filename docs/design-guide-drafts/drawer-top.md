# Design-guide draft: DrawerTop and the mini event card

Status: draft for the Foundation Library. Not public copy.

## DrawerTop

An untitled lead at the top of every room drawer. Authority: Tucker's drawer continuity asks (shared filters, Placez calendar, hologram countdown, Placez-style tag rail).

- A dark gradient fades from the top of the drawer. No heading.
- First: the Placez seven-day calendar rail, used as a date filter. A room may replace this slot (Outzide uses an in-view mini-card rail).
- Second: a wide, short countdown card. It matches the Placez hologram countdown (accent "starts in" language, tabular days / hrs / min). It shows only the names of the next three events and their countdowns. The flyer of the next event is full-bleed behind them.
- Third: tag filters in the Placez filter design (italic display type, category accent, icon) on a horizontal rail that is two rows tall and scrolls sideways. One shared filter config feeds every drawer and map.
- A 1px accent divider separates this block from the first titled section below (In view, Upcoming, Saved, and so on).

## Mini event card

Used for events inside the Placez drawer. Full-bleed flyer, short wide face, event name and a compact countdown on a bottom fade. Share (Apple-style ShareIcon) sits top-right. The heart sits bottom-right and uses the open event card treatment: accent ring, no orange fill plate. Hearts mean interested.

The Placez map In View rail is a different object: standard small cards for every event and place currently on the map, mixed.
