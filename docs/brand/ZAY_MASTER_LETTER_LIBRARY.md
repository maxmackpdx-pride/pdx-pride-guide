# ZAY Master Letter Library — Source of Truth

**ZAY LOGO SYSTEM · MASTER GLYPH LIBRARY · SOURCE OF TRUTH**

Reference image: `docs/brand/assets/ZAY_master_letter_library.png`

This is the authoritative glyph system for the **ZAYLIST** wordmark and all ZAY
lockups. Any wordmark, product name, or lockup built for the brand must be
constructed from these glyphs, at these proportions, without alteration. When
building or regenerating the hero wordmark or any ZAY lockup, this file — not an
approximation — is the reference.

## Scope — NOT a font

> **This is a special-title glyph set, not a typeface.** It does **not** replace
> any font anywhere. Use it **only** to hand-build ZAY-branded titles and
> lockups (e.g. `ZAYLIST`, `HAÜS`, `HAÜSING`, product/section wordmarks).
> All body copy, UI text, buttons, labels, and running text keep the site's
> normal fonts (Barlow Condensed / display + body stacks). Never set paragraphs,
> nav, or interface text in these glyphs, and never map these to a `@font-face`.

## Locked prime ZAY

- The wordmark is **ZAYLIST™** (all caps, trademark where a ™ is used).
- The lockup is **locked** — do not redraw, restretch, or re-space it.
- The **rainbow arc** sits beneath the wordmark (see "The Rainbow Arc" below).

## Y handoff guide

- The **Y** is the connection point in the ZAY system.
- **Y exit point alignment**: the next letter starts at the Y's right vertical
  edge ("next letter starts here") so glyphs connect seamlessly. Preserve this
  exit point when assembling any lockup that follows the Y.

## Glyph inventory (in the library)

Provided glyphs share the ZAY core geometry: **B D F G H I K L M O R S T Ü V !**
(plus the Y handoff glyph and the locked ZAYLIST lockup). The umlaut **Ü** is
included for HAÜS / HAÜSING lockups.

## Notes (rules)

- All letters share the **ZAY core geometry, stroke weight, and blade angles**.
- Use this library to build ZAY wordmarks and lockups.
- **Do not alter proportions, angles, or terminal treatments.**
- Maintain clearspace and alignment per brand guidelines.

## Specifications

- **Geometry:** 45° primary angles with custom blade terminals.
- **Stroke weight:** unified heavy weight across all glyphs.
- **Style:** angular, technical, forward-driving.
- **Usage:** ZAY logo system, wordmarks, product names.
- **Colors:** see brand guidelines (primary: **white on black**).

## The Rainbow Arc

- **Fixed proportions and curvature** — do not reshape.
- **Always centered under lockups.**
- **Do not reshape or reposition.**
