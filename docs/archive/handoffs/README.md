# Archived pairwise handoffs

These were point-to-point handoff documents, one per model pair. That pattern
grows as N by N every time a model joins, and no agent reads the file addressed
to a different model.

They are kept for history. Do not write new ones.

Current handoff lives in `foundation/agent-continuity/`, which every agent reads
regardless of which model it is. Durable decisions live in
`foundation/decisions/`. Raw session thinking lives in
`foundation/explorations/`.
