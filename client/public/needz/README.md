# NEEDZ torn paper masks

Derived from `client/public/boardz/punk/torn-card-scan.webp` (the Boardz torn-card scan) on 2026-11-12.

- `needz-torn-fibers.webp`: alpha = the scan's ripped rim fibers (its colored fringe). Filled in CSS with the card accent token, so the torn fibers always match the card edge color.
- `needz-torn-paper.webp`: alpha = the scan's black paper body, complementary to the fibers. Filled with `--z-black`.

Both are white RGB with alpha only; color comes from tokens in `NeedzDecks.css`.
