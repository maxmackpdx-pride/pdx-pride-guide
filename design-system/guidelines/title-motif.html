Title motif

Dynamic text: the household or person name set bold over the HAÜSING cover photo. Same frame on Looking, Offering, and Managed. Forming uses the same height band and a wider frame so type fills the long card.

Live truth · HousingWell.tsx · updated 2026-07-28

Do not change photo well height to fix type size. Well is 240px (190 mobile). Only the title frame and scale change. Product: client/src/components/housing/HousingWell.tsx.

03 · Type rules

  • At most two lines, all caps; trailing HAÜS alone on line 2.
  • One shared block width; every line fills that width (dynamic column).
  • Equal line heights inside the frame; fill width then fit height.
  • Barlow Condensed 900, fill --text-hi, hard drop shadow on .hz-well__name.
  • Composer: ~3 words / ~22 characters before HAÜS.

05 · Prompt with this name

Say title motif, dynamic text, or HAÜSING name-over-cover. Name half vs Forming frame shares if you change layout. Do not ask to “make the cover shorter” when you only want the type box adjusted.
