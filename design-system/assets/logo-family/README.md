# Zaylist logo family

This folder is the organized source library supplied by Tucker on 2026-08-03. Preserve each SVG's paths, gradients, clipping, spacing, and background treatment. Do not add a TM.

## Current identities

- `zaylist-primary.svg`: default Zaylist website wordmark; replaces the former generic wordmark.
- `zaylist-portland.svg`: Portland edition, available when the city context is explicit.
- `prime-z.svg`: compact icon, avatar, badge, and small-space mark.
- `gigz.svg`: GIGZ board identity and eligible page title.
- `gifz.svg`: GIFZ board identity and eligible page title.
- `THE-HAUZ-Corner-Candidate.svg`: owner-directed THE HAÜZ title artwork. The file remains labeled Candidate until final artwork approval.
- `ideaz.svg`: IDEAZ submission/build-next identity.

## NEXT and future identities

- `z-space.svg`: Z/SPACE.
- `afterz.svg`: AFTERZ.
- `z-out.svg`: Z/OUT.
- `zenegades.svg`: ZENEGADES.
- `zaydark-dark background-finish-pixel-locked.svg`: ZAYDARK.

NEXT placement communicates direction, not that a destination is launched. A future identity may intentionally have no route yet.

## Variants

- `*-on-black.svg` files are presentation variants for dark surfaces, not separate identities.
- `ZAylist Solid White Dark*.svg` files are alternate solid-white Zaylist treatments for dark surfaces.
- PNG files are raster convenience exports; use SVG wherever possible.
- `zaydark-display-finish-pixel-locked.svg` and `ZAylist Solid White Dark.svg` contain embedded raster artwork. Prefer their editable-vector siblings where the visual result is equivalent.

Public copy is exactly **THE HAÜZ**. Its canonical route is `/the-hauz`; legacy public routes may redirect, while internal API and data names remain unchanged.
