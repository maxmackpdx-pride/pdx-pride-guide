Maps

One surface recipe, four placements: the Events board, the home strip, the Directory island, and the two beaches. The frame is a debossed OLED well, thin black outline with inward-only shadow. Nothing on a map carries an outer glow, not the frame, not the key, not a single pin. Values are ported from client/src/components/ds/mapTheme.ts and client/src/index.css; the chrome rule is docs/LIVE_DESIGN_STANDARD.md.
