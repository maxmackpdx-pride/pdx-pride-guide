# Mirror notes

This folder mirrors the public design guide
[`maxmackpdx-pride/zaylist-design-system`](https://github.com/maxmackpdx-pride/zaylist-design-system)
(live: https://maxmackpdx-pride.github.io/zaylist-design-system/).

**Source of truth:** that package / this folder. Not the old portable
`tokens.css` + `previews/*.html` kit.

Intentionally omitted from the main app repo (still on the public Pages repo):

- `uploads/` — Claude export working dumps (~229MB)
- `_eb/` — export build artifacts
- probe/export helper HTML
- oversized one-off aurora source JPG

Everything else (tokens, guidelines, components, brand-guide, app-face,
assets, ui_kits, index shell, handoff) is included.

**Always keep:** `.nojekyll` — required on the public Pages repo so Jekyll
does not strip `_ds_bundle.js` / `_spec.js` (blank specimen iframes).
`npm run sync:design-system` re-touches this file after every mirror.
