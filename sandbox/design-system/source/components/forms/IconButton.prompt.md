**IconButton**, circular single-glyph button for toolbar/nav actions (share, filter, close, map pin).

```jsx
<IconButton label="Share" variant="outline"><i data-lucide="share-2"></i></IconButton>
<IconButton label="Add to calendar" variant="solid"><i data-lucide="calendar-plus"></i></IconButton>
```

- **variant**: `outline` (default), `solid` (hot-pink), `ghost`.
- **size**: `sm` (34) / `md` (44) / `lg` (52).
- `label` is required. Icons come from Lucide (see ICONOGRAPHY in readme).
